# Jensen Jump 
Jensen Jump is a 2D vertical platformer developed in Godot 4 for the Hack Club Haven YSWS, based on the theme **bounce**.

Play as Jensen Huang and bounce your way upwards using RTX5090 platforms. Avoid dangerous obstacles (spikes), collect powerups, and try to beat your highest score. 

# Gameplay
The objective is to climb as high as possible by bouncing between platforms. 
- Bounce automatically when landing on RTX5090 platforms.
- Move left and right to reach the next platforms.
- Avoid spikes that can cost you a life.
- Collect powerups to gain temporary advantages.
- Keep climbing and try to set a new high score.

# Controls
|Key|Action|
|---|---|
|A|Move left|
|D|Move right|
|R|Restart after game over| 

# Features
- **Automatic bouncing**: The character automatically bounces when landing on platforms.
- **Procedurally generated platforms**: New platforms are generated as the player climbs.
- **Hazards**: Avoid spike obstacles along the way.
- **Powerups**: Collect powerups for additional gameplay effects.
- **Health system**: The player starts with three lives.
- **Distance based scoring**: Score increases based on the highest distance climbed.
- **High score tracking**: The game saves your best score locally.
- **Sound effects**: Includes background music, bouncing sounds, and powerup collection audio.
- **Custom UI**: Includes a game over screen, score display, and high-score display.

# Built with 
- Godot 4: Game engine
- GDScript: Game logic and mechanics
- Piskel: Game sprites and visual assets
